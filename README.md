## ✨ Features

| Category | Description |
|-----------|-------------|
| 🌀 **Morphing** | Smooth transitions between 3D objects with shape interpolation |
| 🔥 **Particles** | Pre-configured particle systems (fire, smoke, explosion, snow) |
| 🏙️ **Procedural** | Generation of cities, landscapes, and animated procedural structures |
| 💥 **Effects** | Explosion, dissolution, growth, waves, fracture, cloth |
| 📹 **Export** | Batch rendering, video export, image sequences |
| 🎥 **Camera Rig** | Pre-built camera rigs (orbit, tracking, crane) |
| 💡 **Lighting** | Dynamic lighting setups with automatic keyframes |

## 🚀 Installation

### Method 1: From Releases (Recommended)
1. Download the latest release from [the Releases page](https://github.com/votre-username/anim3d/releases)
2. In Blender: `Edit > Preferences > Add-ons > Install...`
3. Select the downloaded `.zip` file
4. Enable the **Animation: Anim3D** addon

### Method 2: From source code
```bash
git clone https://github.com/votre-username/anim3d.git
cd anim3d
# Copy the src/anim3d folder to Blender's addons directory
```
