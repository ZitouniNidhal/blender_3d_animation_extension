## ✨ Fonctionnalités

| Catégorie | Description |
|-----------|-------------|
| 🌀 **Morphing** | Transitions fluides entre objets 3D avec interpolation de formes |
| 🔥 **Particules** | Systèmes de particules pré-configurés (feu, fumée, explosion, neige) |
| 🏙️ **Procédural** | Génération de villes, paysages, et structures procédurales animées |
| 💥 **Effets** | Explosion, dissolution, croissance, vagues, fracture, tissu |
| 📹 **Export** | Rendu batch, export vidéo, séquence d'images |
| 🎥 **Camera Rig** | Rigs de caméra pré-construits (orbite, travelling, crane) |
| 💡 **Lighting** | Setups d'éclairage dynamiques avec keyframes automatiques |

## 🚀 Installation

### Méthode 1 : Depuis les Releases (Recommandé)
1. Téléchargez la dernière release depuis [la page Releases](https://github.com/votre-username/anim3d/releases)
2. Dans Blender : `Edit > Preferences > Add-ons > Install...`
3. Sélectionnez le fichier `.zip` téléchargé
4. Activez l'addon **Animation: Anim3D**

### Méthode 2 : Depuis le code source
```bash
git clone https://github.com/votre-username/anim3d.git
cd anim3d
# Copiez le dossier src/anim3d dans le répertoire addons de Blender
```
